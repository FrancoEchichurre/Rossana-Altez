## 🎯 ¿Para qué es este proyecto?

**Rossana Altez** es un sitio web moderno dedicado a ofrecer servicios de coaching y mentoría holística.

El **propósito principal** de este proyecto es:
    1.  **Transformación Personal**: Facilitar el acceso a programas de coaching que integran mente, cuerpo y espíritu.
    2.  **Experiencia Visual Inmersiva**: Utilizar animaciones y diseños limpios para transmitir calma y profesionalismo.
    3.  **Catálogo de Cursos**: Presentar de manera clara y atractiva la oferta de cursos y talleres disponibles.

No es solo un sitio informativo; es una plataforma construida con las últimas tecnologías web para asegurar rendimiento y accesibilidad.

## 📖 ¿De qué se habla en la página?

El sitio está estructurado para guiar al usuario a través de los servicios y la filosofía de Rossana Altez. El contenido incluye:

*   **1. Hero Section**: Introducción impactante con efectos visuales (`ParticleBackground`, `RotatingText`) que capturan la esencia de la marca.
*   **2. Catálogo de Cursos**: Lista dinámica (`HolisticCoursesList`) que muestra los programas disponibles mediante tarjetas interactivas (`CourseCard`).
*   **3. Testimonios**: Carrusel (`TestimonialCarousel`) que destaca las experiencias de éxito de los clientes.
*   **4. Interacciones Fluidas**:
    *   *Animaciones*: Elementos que aparecen al hacer scroll (`ScrollReveal`) y contadores animados (`AnimatedCounter`).
    *   *Navegación*: Cabecera inteligente (`Header`) y botón de retorno al inicio (`ScrollToTop`).
*   **5. Diseño Moderno**: Uso de componentes UI consistentes y tipografía cuidada (Geist, Playfair Display) para una lectura agradable.

## 🛠 Tecnologías Utilizadas

Este proyecto fue construido seleccionando cuidadosamente un stack moderno para garantizar rendimiento, SEO y escalabilidad.

| Tecnología | ¿Por qué se usó? |
|:--- |:--- |
| **[Next.js 16](https://nextjs.org/)** | Utilizamos la última versión del framework para producción. Aprovechamos el *App Router* y Server Components para un rendimiento óptimo. |
| **[React 19](https://react.dev/)** | Base de la interfaz de usuario, permitiendo una arquitectura de componentes moderna y robusta. |
| **[Tailwind CSS 4](https://tailwindcss.com/)** | Framework de estilos *utility-first* en su versión más reciente para un diseño totalmente responsive y animaciones fluidas. |
| **[Radix UI](https://www.radix-ui.com/)** | Componentes *headless* accesibles utilizados como base para los elementos de UI complejos, asegurando accesibilidad y personalización. |
| **[Lucide React](https://lucide.dev/)** | Iconografía vectorial ligera y consistente que enriquece la interfaz visual. |
